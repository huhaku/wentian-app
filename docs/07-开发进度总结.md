## 一、项目概况

### 1.1 项目目标
开发一款 Android 原生天气应用，具备以下核心能力：
- 实时天气显示（温度、湿度、风速、气压等）
- 7 天天气预报
- 24 小时逐小时预报
- 空气质量指数（AQI）显示
- 城市搜索与城市切换
- 桌面小部件（显示时间、日期、天气信息）
- 设置项配置（刷新间隔、API 参数）
- 简体中文界面

### 1.2 技术选型
- **开发语言：** Kotlin
- **UI 框架：** Jetpack Compose + Material Design 3
- **架构模式：** MVVM + Repository Pattern
- **依赖注入：** Dagger Hilt
- **数据存储：** SharedPreferences + Room（结构已保留）
- **网络请求：** Retrofit + OkHttp + Moshi
- **异步处理：** Kotlin Coroutines + Flow
- **后台任务：** WorkManager

## 六、问题与解决方案沉淀

### 6.1 已解决的核心问题
1. **WorkManager 初始化导致启动崩溃**
   - 解决：将初始化时机从 `Application` 调整到 `MainActivity`
2. **横竖屏状态显示异常**
   - 解决：统一使用 `collectAsStateWithLifecycle()`
3. **Moshi 无法创建 Converter**
   - 解决：为 Moshi 添加 Kotlin 反射适配
4. **城市搜索接口持续 404**
   - 解决：拆分 `QWeatherGeoApi`，使用官方 GeoAPI 路径
5. **错误信息不可复制**
   - 解决：错误页增加文本选择/复制能力
6. **7 天预报星期全部显示为周三**
   - 解决：修正星期计算逻辑
7. **搜索无结果时抛出 400 错误**
   - 解决：仓库层将 400/404 转换为空结果

### 6.2 当前接口使用原则
- 天气数据接口与城市搜索接口分离
- API Key 通过统一网络拦截器自动拼接
- 未配置或配置错误时优先给出明确提示
- 搜索无结果按正常业务空态处理，不视为程序错误
